# Proposition de post — à publier après la sortie de la version 1.0

TrackIt passe en version 1.0 !

Quand j’ai commencé ce projet, je voulais surtout mieux organiser ma recherche d’alternance : retrouver mes candidatures, mes contacts et savoir qui relancer.

Aujourd’hui, je lui ajoute plus de liberté côté IA. Tu peux utiliser ton propre accès API OpenAI, Gemini ou Claude, ou garder Ollama pour faire fonctionner l’assistant localement. Le choix se fait dans les paramètres, et tu peux changer sans perdre tes conversations.

L’application reste installée sur ton ordinateur. Si tu choisis une API, les informations utiles à ta demande sont envoyées au fournisseur sélectionné avec ton accord.

Tu y retrouves aussi le suivi des candidatures, les coordonnées des recruteurs, les documents associés, l’export Excel et l’extension Chrome pour enregistrer des offres.

📥 Télécharger pour Mac, Windows ou Linux :
https://github.com/mohammadmasah/Job-Tracker-Aggregator/releases/latest

🛠️ Explorer le code ou contribuer :
https://github.com/mohammadmasah/Job-Tracker-Aggregator

Pas besoin de Docker pour utiliser la version téléchargeable. L’installation Docker reste proposée aux développeurs.

Si tu l’essaies, raconte-moi ce qui t’aide et ce que tu aimerais améliorer. Je cherche toujours une alternance en développement web, et ce projet continue de grandir avec ce que j’apprends et vos retours.
